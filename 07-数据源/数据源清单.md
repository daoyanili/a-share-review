# A股复盘数据源清单

> 目标：先拿复盘真正需要的数据，不为了数据而数据。

## 1. 自在量化

入口：

- https://quant.zizizaizai.com/review/uplimit/reason
- 页面实际请求接口：`https://api.zizizaizai.com/v3/api/review/uplimit/reason?date1=日期&page=页码&page_size=每页板块数`

说明：

- 页面本身是前端加载页，适合人工查看。
- 自动采集时优先使用页面背后的接口或 `zzshare` 接口，不优先硬爬网页元素。
- 个人 Token 可在站点个人资料页获取；大部分接口可先试用，部分实时接口需要 Token。

### 必抓数据

| 数据 | 推荐接口 | 用途 |
|---|---|---|
| 涨停原因页面数据 | `/v3/api/review/uplimit/reason` | 同时拿热门板块、涨停股票、涨停原因、封单、成交额、换手等 |
| 涨停热门板块 | `uplimit_hot(date1)` | 判断当天最强题材 |
| 涨停股票列表 | `uplimit_stocks(date1)` | 生成涨停池、连板梯队 |
| 个股涨停原因 | `stock_uplimit_reason(stock_code, date)` | 写清楚每只涨停股为什么涨 |
| 市场情绪 | `market_sentiment(date1, date2)` | 判断情绪强弱和阶段 |
| 情绪趋势 | `sentiment_trend(model, date1)` | 辅助判断修复、分歧、退潮 |
| 板块排名 | `plates_rank(plate_type, date1)` | 行业、概念、题材强弱排序 |
| 板块成分股 | `market_plate_stocks(plate_type, plate_code, date1)` | 找板块核心个股 |

### 可选数据

| 数据 | 推荐接口 | 用途 |
|---|---|---|
| 龙虎榜列表 | `lhb_list(date1)` | 复盘强势股资金性质 |
| 龙虎榜详情 | `lhb_detail(date1, stock_code)` | 看买卖席位 |
| 同花顺热度 Top | `ths_hot_top(date1, top_n)` | 判断市场关注度 |
| 个股资金流 | `stock_moneyflow(stock_id, m_type)` | 只作辅助，不单独下结论 |
| 异动数据 | `movement_alerts(date1, type, limit, is_real)` | 盘中异动记录 |

## 2. AkShare

用途：

- 指数行情
- 全市场日线
- 涨跌家数辅助
- 行业、概念、资金流等公开数据补充

适合做免费备用数据源。

## 3. Tushare

用途：

- 每日涨跌停、炸板数据
- 日线行情
- 股票基础信息
- 交易日历

说明：

- 稳定性较好，但部分接口需要积分。
- 如果后面做长期历史回测，可以作为主数据源之一。

## 4. 东方财富

用途：

- 板块资金流
- 行业、概念板块排行
- 个股资金流
- 热门股和数据中心页面核对

说明：

- 适合补板块和资金口径。
- 需要注意页面字段变化，采集脚本要保留失败提示。

## 5. 第一版每日采集包

每天先固定抓这几类：

1. 指数涨跌幅和成交额
2. 两市上涨、下跌家数
3. 涨停、跌停、炸板
4. 连板梯队
5. 涨停原因
6. 热门板块和板块内核心个股
7. 市场情绪指标
8. 成交额前排个股
9. 龙虎榜，盘后可选

## 6. 数据落地建议

原始数据先存成表格文件，复盘文章只引用处理后的结论。

建议目录：

| 目录 | 内容 |
|---|---|
| `data/raw/日期/` | 原始接口返回 |
| `data/processed/日期/` | 清洗后的表格 |
| `reports/日期/` | 自动生成的复盘草稿 |

## 7. 注意事项

- 所有数据都要记录来源和采集时间。
- 页面爬取要控制频率，不要高频请求。
- 涨停原因、题材归因要允许人工修正。
- 资金流数据只能辅助判断，不能当成唯一依据。
- 数据用于研究复盘，不用于自动下单。
