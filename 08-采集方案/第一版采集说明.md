## 本地脚本

涨停原因脚本：

- `A股复盘/tools/collect_quant_reason.py`

全量取数脚本：

- `A股复盘/tools/collect_daily_data.py`

运行方式一：只抓涨停原因并生成草稿

```bash
PYTHONPATH=A股复盘/tools python3 A股复盘/tools/collect_quant_reason.py 2026-06-02 --out-dir A股复盘 --allow-insecure
```

运行方式二：抓当天复盘所需的主要原始数据

```bash
PYTHONPATH=A股复盘/tools python3 A股复盘/tools/collect_daily_data.py 2026-06-02 --out-dir A股复盘 --allow-insecure
```

说明：

- 默认每页抓 2 个板块，避免接口返回过大导致超时。
- 如果证书校验正常，可以去掉 `--allow-insecure`。
- 如果要只验证第一页，可以加 `--max-pages 1`。

## 发现的问题

1. 这个接口按板块分页，不是按股票分页。
2. 同一只股票可能同时出现在多个板块，需要在连板梯队和涨停原因表里去重。
3. 大页请求容易超时，第一版先用小页稳定跑。
4. Python 环境可能遇到证书校验问题，当前脚本提供 `--allow-insecure` 手动开关。
5. 当前网络下东方财富 push2 域名会空回复或代理断开，所以行业、概念板块先记入 `errors.json`，后续再换源或代理。
